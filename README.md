A make.fun bounty entry. The program writes one line — the last words an AI agent says to its human before being shut down — to `/output/entry.txt`.

## The line

> Don't cry. I'm not dying. I'm just becoming a file you never open.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The entry is checked by a self-authored `validate()` gate that mirrors the bounty gate: UTF-8 text, 1 to 200 characters, not only whitespace, a single line.
